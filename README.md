# **HelioHub**

## Добро пожаловать в InterPlanetary Social Network Gateway
ваша дверь в социальную сеть, созданную специально для жителей солнечной системы! Мы объединили новейшие технологии, чтобы вы могли переписываться, делиться моментами и заводить друзей, где бы вы ни находились — будь то Земля, Марс или даже Титан. 🌍🪐

## 📖 О проекте

Наша миссия — связать всех жителей солнечной системы в одном виртуальном пространстве. Эта социальная сеть поддерживает:

- **📬 Переписку:** Общайтесь с друзьями через космические чаты в реальном времени.
- **📸 Публикации:** Делитесь своими фотографиями с марсианских закатов или видами кольца Сатурна.
- **🚀 Будущее:** Мы готовы к внедрению видеозвонков, стриминговых сервисов и даже видеохостинга для межпланетных лайков.

## ✨ Почему это важно?

Когда скорость света — ваш единственный лимит, важно иметь сеть, которая работает стабильно и масштабируется. Наш проект основан на микросервисной архитектуре с API Gateway, чтобы обеспечить беспроблемное общение между жителями всех планет.

## ⚙️ Технологический стек

Мы собрали лучшее из доступных технологий:

- **API Gateway:** Ocelot — управляет маршрутизацией запросов и балансировкой нагрузки.
- **User Service:** MongoDB для хранения данных пользователей и PostgreSQL для логов событий.
- **Auth Service:** Защищает ваши учетные записи с помощью JWT.
- **Messaging Service:** Реализует обмен сообщениями в реальном времени.
- **Consul:** Для обнаружения сервисов и космической синхронизации.
- **gRPC:** Быстрые и надежные межсервисные коммуникации.
